# Vention Printer Interface — Plan 3: Studio UI

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Vite + React + TS operator UI in the FLIR Studio layout (tool strip / to-scale machine view / rail / plot dock / status bar) driving the Plan 1+2 backend over `/api/*` and `/ws/telemetry`, gated exactly like the T&C tool.

**Architecture:** Copy the FLIR frontend shell verbatim where it is generic (theme tokens, studio grid + components, layout/operator/api libs, test conventions), rename the family prefix to `vpi`, and add printer-specific pure logic in `src/lib/` (recipe compiler mirror, machine-view geometry, telemetry types, formatting) with `node --test`. Components are browser-verified against `vpi-serve --backend simulated`.

**Tech Stack:** Vite 5, React 18, TypeScript 5, `node --experimental-strip-types --test`; no other runtime deps. Ports 5175 (dev) / 8020 (operator). Header `X-VPI-Client`. localStorage `vpi.*.v1`.

**Spec:** `docs/superpowers/specs/2026-09-08-vention-printer-interface-design.md` §6.
